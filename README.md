# Бот записи в груминг-студию «Тихая лапа» (прототип)

Telegram-бот для записи клиентов к мастеру. Всё в одном сообщении, которое
редактируется по ходу диалога, инлайн-кнопки, минимум эмодзи.

Данные салона и мастера (Екатерина Воронцова, адрес, телефон, цены) **вымышленные**.
Замените их на свои в файле `content.py`.

## Что умеет бот

**Клиент:** приветствие, услуги и цены, раздел «О специалисте», запись за 6 шагов
(услуга → размер собаки → день → время → кличка и порода → контакт), «Мои записи»
с переносом и отменой, контакты и график работы, напоминания о визите за сутки и за 2 часа.

**Мастер** (команда `/admin`): уведомление о новой записи с кнопками «Принять» и
«Отклонить», списки записей на сегодня, завтра и ближайшие дни, отмена записи,
закрытие дня или части дня, снятие закрытия.

## Быстрый старт

Нужен Python 3.10 или новее.

1. Откройте терминал в папке проекта и установите библиотеки:
   ```
   pip install -r requirements.txt
   ```
2. Создайте бота в Telegram: напишите `@BotFather`, команда `/newbot`, скопируйте токен.
3. Узнайте свой Telegram ID: напишите боту `@userinfobot`.
4. Скопируйте `.env.example` в `.env` и заполните:
   ```
   BOT_TOKEN=токен_от_BotFather
   ADMIN_IDS=ваш_telegram_id
   ```
5. Запустите:
   ```
   python bot.py
   ```
   В терминале появится строка «Бот запущен». Откройте бота в Telegram и нажмите Start.

Если на компьютере команда `python` не находится, используйте `python3` (Mac, Linux)
или `py` (Windows).

## Как показывать на созвоне

- Укажите свой ID в `ADMIN_IDS`: тогда и клиентские сообщения, и уведомления мастера
  придут в один чат, и вы покажете обе стороны. Панель мастера открывается кнопкой
  в главном меню или командой `/admin`.
- Чтобы календарь выглядел живым, выполните один раз `python seed_demo.py`: добавятся
  вымышленные записи на ближайшие рабочие дни.
- Чтобы начать с чистого листа, остановите бота и удалите файл `data/bot.sqlite3`.
- Хотите, чтобы запись подтверждалась сразу, без «Принять»: `AUTO_CONFIRM=true` в `.env`.

## Оформление профиля бота

В `@BotFather`: `/setuserpic` и загрузите `assets/avatar.png`, `/setname` для имени.
Описание и команды бот выставляет сам при запуске.

## Что менять под реального клиента

Всё в файле `content.py`, открывайте обычным блокнотом:

- название, адрес, телефон салона и данные мастера;
- услуги, цены и длительность по размерам собак;
- график работы, перерыв, шаг записи, на сколько дней вперёд можно записаться.

Картинки в папке `assets`: `welcome.jpg` (главное меню) и `master.jpg` (раздел о специалисте).
Сейчас это заготовки с названием и именем. Положите настоящую фотографию мастера под тем же
именем `master.jpg`, формат 16:9 (например, 1280×720). Если файла нет, бот покажет текст без картинки.

После правки перезапустите бота.

## Запуск круглосуточно

На обычном компьютере бот работает, пока компьютер включён и открыт терминал. Для клиентов нужен
сервер (VPS): подойдёт самый дешёвый тариф с Linux. Пример службы `systemd`
(`/etc/systemd/system/grooming-bot.service`):

```
[Unit]
Description=Grooming bot
After=network-online.target

[Service]
WorkingDirectory=/opt/grooming_bot
ExecStart=/opt/grooming_bot/.venv/bin/python bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```

Затем: `systemctl enable --now grooming-bot`.

## Устройство проекта

| Файл | Назначение |
|---|---|
| `bot.py` | запуск |
| `content.py` | тексты, услуги, цены, расписание |
| `handlers/client.py` | экраны и запись клиента |
| `handlers/admin.py` | панель мастера |
| `slots.py` | расчёт свободного времени |
| `db.py` | база SQLite, файл `data/bot.sqlite3` |
| `notify.py`, `reminders.py` | уведомления и напоминания |
| `seed_demo.py` | демо-записи |

## Ограничения прототипа

- Один мастер и один график. Для нескольких мастеров нужна доработка.
- Незавершённая запись хранится в памяти: при перезапуске бота клиент начнёт её заново.
  Уже созданные записи в базе не теряются.
- Оплаты и предоплаты нет.
- Стоимость в боте ориентировочная, итоговую мастер уточняет на месте (это указано в тексте).
